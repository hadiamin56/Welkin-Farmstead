# Welkin Farmstead — Where Goodness Grows

Static website, no build step. Publish directory = repo root.

## Add your real HD photos
Put JPGs in `assets/photos/` using these exact names (landscape ≥ 2400px wide for `hero`, ≥ 1600px for the rest):

| file | where it shows |
|---|---|
| hero.jpg | full-screen hero (wide orchard / valley shot) |
| orchard.jpg | Orchard chapter, large portrait |
| cherries.jpg, nectarines.jpg, walnuts.jpg | Orchard trio |
| trout.jpg | Water chapter, large portrait |
| sheep.jpg | Herd chapter, large portrait |
| bull.jpg, merino.jpg | Herd pair (wide) |
| paddy.jpg | Field chapter, large portrait |

Missing photos show a labelled placeholder; present ones replace it automatically.

## Edit
- WhatsApp number: `WA` in `script.js`
- Season chart: `CROPS` in `script.js`
