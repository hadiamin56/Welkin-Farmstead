# Welkin Farmstead — Where Goodness Grows

Static website (no build step). Open `index.html` or host the folder anywhere (GitHub Pages, Netlify…).

## Add your real photos
Drop JPGs into `assets/photos/` named: `apple.jpg cherries.jpg trout.jpg sheep.jpg paddy.jpg walnuts.jpg kiwi.jpg pears.jpg`.
Each gallery tile shows the photo automatically; without one it shows an illustration.

## Edit content
- Phone / WhatsApp number: `WA` in `script.js`
- Seasonal calendar data: `CROPS` in `script.js`
